# Changelog

## 0.2.0

- Replaced the graphical page with a basic command-line style interface.
- Added `import .epub`, `view imports`, and `back` commands.
- Added a persistent list of converted books and their Kindle addresses.
- Added a separate `>` cursor with Up Arrow, Down Arrow, and Enter controls.

## 0.1.0

- Added a local EPUB-to-AZW3 conversion service.
- Pinned the conversion engine to calibre 8.5.0.
- Added a drag-and-drop browser interface.
- Added short local-network download addresses for Kindle.
- Added EPUB validation, upload limits, and conversion error messages.
